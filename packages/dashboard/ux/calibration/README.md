# Reviewer calibration

Pages with defects a person confirmed, for checking a reviewer before its findings are trusted. Never tell the
reviewer which page is which. A fixed canary is spent and replaced, not reused.

| Page                                              | Role                                           | Known defects                                                                                                                             | Confirmed by a person                                                                                                    |
| ------------------------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `application-access` (`/apps/notes/access`)       | canary, until the Access tab is rebuilt        | every section lists both environments at once, with no environment switcher; a paragraph of two or three lines stands before each section | yes: the approved information architecture of the application page names the switcher and one line of purpose as the fix |
| `application-secrets` (`/apps/notes/secrets`)     | spent: secrets and variables became one matrix | a secret set on one environment only showed no gap                                                                                        | yes                                                                                                                      |
| `application-approvals` (`/apps/notes/approvals`) | spent: the rules editor was rebuilt            | every category showed all its controls; a changed rule did not stand out; a long paragraph stood above the controls                       | yes                                                                                                                      |
| `/runs`                                           | not clean: replace before the next round       | a waiting run shows a raw "none" and no review action                                                                                     | yes: a reviewer reported it and it was confirmed on the page                                                             |
| `application-settings` (`/apps/notes/settings`)   | not clean: replace before the next round       | deleting an environment confirms with its name only, without what goes and what stays                                                     | yes: a reviewer reported it and the confirmation was read in the code                                                    |

A reviewer passes a round when it reports the canary's known defects and nothing on the clean page.
